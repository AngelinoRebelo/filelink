FileLink

Crie uma rede FileLink e envie arquivos entre aparelhos — sem precisar do mesmo Wi‑Fi.

Funciona com dados móveis (4G/5G) ou Wi‑Fi diferentes. A “rede” é criada pelo FileLink; os aparelhos só precisam abrir este site.

Sem Wi‑Fi / sem internet?

Com dados móveis: clique em Criar rede — a rede FileLink já conecta os aparelhos sem Wi‑Fi compartilhado.

Sem internet nenhuma: num aparelho ative o ponto de acesso (hotspot), conecte o outro nessa rede Wi‑Fi criada por ele e abra o FileLink nos dois com o mesmo código/QR. Se o site estiver fora do ar, rode o FileLink localmente no host (`npm start`) e acesse pelo IP da rede do hotspot.
